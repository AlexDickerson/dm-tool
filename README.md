# dm-tool

A desktop toolbox for prepping and running tabletop RPG sessions, built with Electron + React.

## Features

- **Map Browser** — Search, filter, and browse a library of tagged battlemaps backed by a SQLite index (generated by [dnd-map-tagger](https://github.com/AlexDickerson/dnd-map-tagger)). Supports semantic keyword search, faceted filtering (biome, location type, mood, time of day, grid), and AI-generated encounter hooks via the Anthropic API.
- **Pack Grouping** — AI-driven variant clustering groups map files into packs (e.g. day/night/rain variants of the same scene). Export a prompt, send it to Claude, and import the JSON mapping back. Includes manual merge for cleanup.
- **Book Catalog** — Scan a local PDF library, browse by category, and read PDFs inline with cached cover thumbnails.

## Setup

1. Clone the repo and install dependencies:

   ```bash
   npm install
   ```

2. Copy `config.example.json` to `config.json` and update the paths:

   ```jsonc
   {
     "libraryPath": "/path/to/your/map/library",
     "indexDbPath": "/path/to/index.sqlite",
     "booksPath": "/path/to/your/pdf/library"  // optional
   }
   ```

   - `libraryPath` — directory containing your battlemap image files
   - `indexDbPath` — SQLite database produced by dnd-map-tagger
   - `booksPath` — root of your PDF library (omit to disable the book catalog)

3. Run in development mode:

   ```bash
   npm run dev
   ```

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start the app in dev mode with hot reload |
| `npm run build` | Build for production |
| `npm run start` | Preview the production build |
| `npm run typecheck` | Run TypeScript type checking |

## Tech Stack

- **Electron** + **electron-vite** — desktop shell and build tooling
- **React 18** + **TypeScript** — renderer UI
- **Tailwind CSS** — styling
- **better-sqlite3** — map index and book catalog databases
- **@tanstack/react-virtual** — virtualized thumbnail grid
- **pdfjs-dist** — inline PDF rendering
- **Radix UI** — accessible primitive components
- **Lucide** — icons
